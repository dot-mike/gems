# Instructions

1. Install the game
2. Copy the released wsock32.dll into `C:\Program Files (x86)\Out of the Park Developments\OOTP 6`
3. Right click OOTP.exe -> Properties -> Compatability -> Check "Run this program in compatability mode for" -> Windows XP (Service Pack 2) -> OK
4. Run OOTP6.exe
5. Click License
6. Click Accept
7. Enter Order ID: 1234
8. Click "Install License"

It should say "Success" if it does not please raise a ticket and attach "%TEMP%/log.txt"
