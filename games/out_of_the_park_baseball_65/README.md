# Instructions

1. You must first license [OOTP6](../out_of_the_park_baseball_6/README.md)
2. Install the game
3. Copy the released wsock32.dll into `C:\Program Files (x86)\Out of the Park Developments\OOTP 6.5`
4. Right click OOTP.exe -> Properties -> Compatability -> Check "Run this program in compatability mode for" -> Windows XP (Service Pack 2) -> OK
5. Run OOTP65.exe
6. Click License
7. Click Accept
8. Enter Order ID: 1234
9. Click "Install License"

It should say "Success" if it does not please raise a ticket and attach "%TEMP%/log.txt"
